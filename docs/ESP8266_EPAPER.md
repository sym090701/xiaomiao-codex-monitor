# ESP8266 墨水屏额度显示（实验性）

这是独立于小喵的早期移植，仅计划在可信家庭局域网读取现有额度服务的 `/usage`，显示五小时和周额度。默认每五分钟查询，失败时每 30 秒重试；数值或在线状态变化时刷新屏幕，同一画面最多保留 24 小时后重新刷新。没有趋势、家外中继、预热、OTA 或配网页面。

**当前默认禁止屏幕驱动输出。** 随附面板规格书与示例的 BUSY 极性不一致，且示例目录名与面板型号不一致；这些材料不足以确认你的实物屏与该初始化序列兼容。默认构建只验证 ESP8266 程序能编译，不能证明显示器可用，也不应视为可交付刷机固件。确认面板型号、控制器、排线和驱动板后，才能在受控实验中启用 `EPD_ALLOW_UNVERIFIED_DRIVER=1` 并确认 `EPD_BUSY_LEVEL`。BUSY 等待设置 45 秒上限；如果在实验时超时，停止测试、断电检查，不能反复盲刷。

实物照片上的屏幕标签为 `SE2266FS092`，而规格书是 `E2266FS092`，不能假定它们是同一修订。板上可见的引脚标识与预设一致；屏幕排线在照片中未连接，FPC 座的接触面方向及管脚定义仍需核验。社区项目有该型号的使用记录，但仅作为参考，不替代实物电气验证。

预设引脚对应微雪 E-Paper ESP8266 Driver Board 官方资料：BUSY=D1/GPIO5、RST=D4/GPIO2、DC=D2/GPIO4、CS=D8/GPIO15、SCK=D5/GPIO14、MOSI=D7/GPIO13。不同驱动板或排线转接板不能照搬；板子是否为这一型号仍需实物确认。ESP8266 的 GPIO2 和 GPIO15 同时是启动配置引脚，硬件需满足其上电电平。参考：[微雪驱动板](https://www.waveshare.com/wiki/E-Paper_ESP8266_Driver_Board)、[ESP8266 启动模式](https://arduino-esp8266.readthedocs.io/en/latest/boards.html)。

默认编译使用公开的 `device.example.json` 测试值，不连接个人账户：

```sh
PLATFORMIO_CORE_DIR="$PWD/.pio/sandbox-core" platformio run -e esp8266_epaper_quota
```

确认硬件后，可通过 `XM_DEVICE_CONFIG_FILE` 指向本机私有设备 JSON；构建脚本只嵌入 Wi-Fi 和局域网服务器配置，不嵌入中继令牌。私有固件包含 Wi-Fi 凭据，不能公开。`nodemcuv2` 环境是编译预设，并非检测到的物理型号或 Flash 容量；连接设备后应先识别硬件、完整备份并确认刷写布局，不能在未知设备上直接上传。

相关显示初始化和 152×296、双平面数据大小参考用户提供的屏幕示例；它们仍须针对实际面板验证。显示颜色极性、方向、清屏、忙碌状态和三色驱动都没有实机验证。
