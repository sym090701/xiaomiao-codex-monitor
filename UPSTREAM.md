# Upstream source and license status

The XiaoMiao firmware and companion are derived from:

- Repository: https://github.com/evoking6/esp32-code-monitor
- Imported source baseline: `3cd0f7bc43bd4d913cbc7b11aa25b2bfa91e3d73`
- XiaoMiao-specific changes: PlatformIO target, ST7735/pin/button adaptation, embedded setup page, unique per-device setup password, Launcher return path, and XiaoMiao documentation.

The imported Git history is intentionally retained. GitHub's Contributors page includes upstream authors because their commits are ancestors of this project. Those entries reflect the code this port builds on; they are not accidental project members.

The imported baseline does not contain a `LICENSE` file. This repository therefore does not claim to relicense the upstream code or grant a new license for it. Check the upstream project for an explicit license or obtain permission from its author before redistributing binaries or using the code beyond permissions granted by applicable law.
